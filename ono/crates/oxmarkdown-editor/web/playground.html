ono / OxMarkdown playground — type OxMarkdown source in the first column (directives, checkboxes, ==highlight==, GFM strikethrough, ...) and see exactly what it converts + renders to in the second, via the SAME convert.rs/doc_view_html pipeline the main editor and SSR both use. The third column re-serializes that SAME parsed document straight back to markdown (serialize.rs) — both read-only, deterministic renders, not second live editors, so nothing here can drift out of sync with the source in the first column. Comparing columns 1 and 3 is the live, hands-on version of this crate's own round-trip tests.
