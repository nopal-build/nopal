ono / oxmarkdown-editor — taino-edit, a real ProseMirror-style Rust document model + contenteditable DOM bridge for Leptos, with NO JavaScript bridge at runtime (unlike Lexical, which this is meant to eventually replace). Now with real OxMarkdown directives (leaf/ container/text), checkboxes, ==highlight==, and GFM strikethrough as real node/mark types — not yet interactive (no click-to-toggle, no directive popovers), but structurally real and losslessly preserved. Try typing directly in the box below, and Mod-b / Mod-i (Cmd or Ctrl) for bold/italic.
