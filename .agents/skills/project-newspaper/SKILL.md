A project newspaper is an interactive view of a project. It will use the README.me file at the root of a project folder in the Vault. Really this is just an interactive view of oxmarkdown. 

The goal of this page is to be be used as a sort of daily (daily can refer to latest updates) view of the project.

The newspaper view is built by using the skills folder defined in the project and for those that have access will be able to create and edit those skills.
